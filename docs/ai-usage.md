# AI 工具使用说明

## 1. 使用背景

在 mall-lite 轻量级商城后端系统开发过程中，使用 AI 工具辅助完成需求拆解、技术方案学习、代码编写、问题排查、测试用例设计和项目文档撰写，以提升开发效率和学习效果。

## 2. 使用工具

- ChatGPT
- deepseek

## 3. 使用场景

### 3.1 需求拆解

使用 AI 辅助将商城业务拆解为用户认证、权限控制、商品管理、订单管理、库存扣减、缓存优化、超时订单处理等模块，并整理各模块的接口清单和业务流程。

### 3.2 技术学习

使用 AI 辅助学习 JWT 认证、ThreadLocal 用户上下文、RBAC 权限模型、Redis Cache Aside 缓存模式、Spring Task 定时任务、事务控制等技术点，并结合项目代码进行实践。

### 3.3 代码编写辅助

在实现登录拦截器、权限注解、Redis 商品详情缓存、订单状态流转、库存扣减等功能时，使用 AI 辅助生成初版思路或代码片段，并根据项目结构进行修改和验证。

### 3.4 Bug 排查

使用 AI 辅助分析接口返回异常、JWT Token 校验失败、Redis 缓存读取异常、库存扣减失败、订单状态流转错误等问题，并结合控制台日志、数据库数据和接口返回结果定位原因。

### 3.5 测试辅助

使用 AI 辅助整理 Postman 测试流程，覆盖用户登录、商品查询、创建订单、模拟支付、取消订单、管理员发货、确认收货等核心接口。

### 3.6 文档撰写

使用 AI 辅助整理 README、接口测试说明、数据库初始化说明、AI 工具使用说明等项目文档。

## 4. 使用原则

AI 生成内容不直接照搬，必须经过以下步骤：

1. 理解生成内容的逻辑。
2. 结合项目实际代码进行调整。
3. 本地运行项目进行验证。
4. 使用 Postman 或单元测试验证接口结果。
5. 结合报错日志和官方文档修正不准确内容。

## 5. 项目中的具体例子

### 5.1 JWT 与 ThreadLocal

使用 AI 辅助分析登录态校验流程，明确通过拦截器解析 Token，并将当前用户信息保存到 ThreadLocal 中，请求结束后及时清理，避免线程复用导致用户信息污染。

### 5.2 Redis 商品详情缓存

使用 AI 辅助梳理 Cache Aside 模式：查询商品详情时优先读取 Redis，缓存未命中时查询 MySQL 并写入缓存；商品修改、下架、库存扣减或恢复时删除缓存，保证数据最终一致性。

### 5.3 订单状态流转

使用 AI 辅助整理订单从待支付、已支付、已发货、已完成、已取消的状态流转规则，并结合业务校验避免非法状态变更。

### 5.4 Postman 接口测试

使用 AI 辅助规划 Postman 接口集合结构，按用户认证、商品模块、订单模块进行分类，并通过环境变量自动保存和复用 JWT Token。
